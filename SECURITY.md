# Security Policy

## Supported versions

| Version | Supported                                   |
| ------- | ------------------------------------------- |
| 0.1.x   | Yes (best effort; this is an early release) |

## Reporting a vulnerability

If you find a security vulnerability in BanglaA11y, please do **not** open a
public issue. Instead, open a private security advisory on GitHub, or contact
the repository owner through GitHub.

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce it
- The version affected
- Any suggested fix, if you have one

We will acknowledge receipt, investigate, and coordinate a fix and disclosure.
There is no fixed SLA for this early-stage project; we will be honest about
timelines in the advisory thread.

## Scope notes

BanglaA11y audits other people's websites by loading them in a browser.
Running it against a site you do not own or do not have permission to test
may violate that site's terms or local law — only audit sites you own or
have explicit permission to test. Audit results themselves can include
snippets of the audited page; treat generated reports as potentially
containing third-party content and do not publish them without review.
